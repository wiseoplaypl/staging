# Multi Accessories with Checkboxes
-----------------------------------
## DESCRIPTION
--------------------
# This simple module boost your sales with cross-selling. It shows all the accessories (Image, name & price) with checkboxes on product page. User can select as per there need. so when user clicks on Add_to_cart button, it will also add selected accessories into cart in background.
## FEATURES
---------------------
    Boosts in cross-sales.
    Easy for customers to buy accessories quickly
    Enhance user experience
	Multi accessories list available with checkboxes on product page.
    Shows accessory image, name and price for customer satisfaction.
	Offer combinations for accessories products to be able to select.
    Auto add the selected accessories in cart when user add product to cart.
    Works in product Quick-view screen.
    Enhances the user experience.
    No configuration required.
    Add selected accessory products in background with no redirection.
    No overrides. Just uses Prestashop inbuilt features.
	  Optional related products as accessories on product page.
    Saves time for customers who needs to buy related products.

# INSTALL
----------
Just upload the zip file to install it and you're ready to go. No configuration required.
